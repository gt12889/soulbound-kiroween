# Spirit Companion Skill Tree Documentation

## Overview

Each Spirit Companion has a unique skill tree with three branches:
- **Power**: Productivity enhancements and task-related abilities
- **Wisdom**: Dialogue options and experience bonuses
- **Charm**: Visual animations and idle behaviors

Skills are unlocked using skill points earned by leveling up. Each level grants 1 skill point.

## Experience and Leveling

- **Base Experience**: 100 XP for level 1→2
- **Scaling**: Exponential (baseXP × level^1.5)
- **Skill Points**: 1 point per level (starting at level 2)

## Skill Effect Types

### Ghost Writer Hints
Enhances the AI writing suggestions in the Ghost Writer module. Higher values provide more detailed and frequent suggestions.

**Stacking**: Yes (values add together)
**Max Value**: 3 (from unlocking all power branch skills)

### Task Prediction
Improves the companion's ability to predict which tasks you should focus on next.

**Stacking**: No (uses highest value)
**Values**: 75% (Forest), 80% (Shadow), 85% (Ember)

### Dialogue Unlock
Adds new dialogue categories that the companion can use when speaking to you.

**Categories**:
- Shadow: philosophical, introspective, mysterious
- Forest: nature, growth, patience
- Ember: motivational, inspirational, energetic

### Animation Unlock
Adds new special animations that play during interactions or celebrations.

**Animations**:
- Shadow: phantom_dance, shadow_weave
- Forest: leaf_swirl, guardian_aura
- Ember: flame_dance, solar_burst

### Idle Behavior
Adds new passive animations that play when the companion is idle.

**Behaviors**:
- Shadow: mist_dissolve
- Forest: bloom_pulse
- Ember: warm_pulse

### XP Boost
Increases experience gained from all activities.

**Stacking**: Yes (values add together)
**Values**: 25% (Shadow), 30% (Forest), 35% (Ember)

## Skill Progression Strategies

### Early Game (Levels 1-5)
Focus on unlocking first-tier skills across all branches to get a variety of abilities.

**Recommended Order**:
1. Power branch skill (Ghost Writer hints)
2. Wisdom branch skill (dialogue options)
3. Charm branch skill (animations)

### Mid Game (Levels 6-10)
Start building toward second-tier skills in your preferred branch.

**For Productivity**: Focus on Power branch
**For Personality**: Focus on Wisdom branch
**For Aesthetics**: Focus on Charm branch

### Late Game (Levels 11+)
Complete skill chains to unlock third-tier abilities.

**Power Players**: Complete power branch for maximum Ghost Writer enhancement
**XP Farmers**: Complete wisdom branch for XP boost
**Collectors**: Complete all branches for full companion experience

---

## Tips

1. **Plan Ahead**: Skills have prerequisites, so plan your path before spending points
2. **No Respec**: Choose carefully - skill points cannot be refunded (yet)
3. **Balanced Build**: Consider unlocking at least one skill from each branch for variety
4. **XP Boost Last**: Save XP boost skills for later when you have more activities to benefit from
5. **Companion Switching**: Each companion keeps their own skill tree, so you can experiment with different builds
