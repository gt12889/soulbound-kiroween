Animation Stages

Bounce
0.6 seconds

2.0 seconds

Shine
1.0 second
Light sweeps across

Animation Features

  • Bounce Effect: Tokens scale to 1.2x and rotate ±5°
  • Glow Pulse: Box shadow expands from 12px to 36px
  • Shine Effect: Gradient sweeps from left to right
  • Duration: 2 seconds total (overlapping animations)
  • Trigger: Auto-detects token count increase
  • Manual: Can be triggered via onTokenEarned prop
  • Accessibility: Respects prefers-reduced-motion

When Animation Triggers

  • ✅ Token count increases (e.g., 1 → 2)
  • ✅ onTokenEarned prop set to true
  • ❌ Token count decreases (using a token)
  • ❌ Token count stays the same
  • ❌ Component first mounts
