Error Mapping Flow

1
Error Occurs
Network failure, API error, timeout, etc.
↓
2
State Machine Creates GhostWriterError
Error is categorized with type, message, and retryable flag
↓
3
GhostWriter Passes Error to Display
Both error message and type are provided
↓
4
GhostErrorDisplay Maps to Friendly Message
Uses explicit type or pattern matching on error text
↓
5
Display Error with Context
Shows friendly message, context help, and technical details
