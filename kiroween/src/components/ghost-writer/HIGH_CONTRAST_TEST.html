Testing Instructions

  1. Simulated Mode: Click the "Toggle High Contrast Mode" button above to see the simulated high contrast styles.
  2. Real System Mode (Windows): Go to Settings → Accessibility → Contrast themes → Select a high contrast theme
  3. Real System Mode (macOS): System Preferences → Accessibility → Display → Check "Increase contrast"
  4. Browser DevTools: Open DevTools → Rendering → Emulate CSS media feature prefers-contrast → Select "high"

What to Look For:

  • Text should be pure white (#ffffff) for maximum readability
  • Borders should be thicker (3-4px) and more visible
  • Background colors should have higher opacity
  • All interactive elements should be clearly distinguishable
  • Decorative effects (shadows, glows) should be reduced or removed
