Features

  • ✅ Shows highest current streak across all types
  • ✅ Fire icon with flickering animation
  • ✅ Tooltip displays all streak details
  • ✅ Warning badge when any streak at risk
  • ✅ Pulse animation for at-risk state
  • ✅ Click navigates to /streaks dashboard
  • ✅ Keyboard accessible (Enter/Space)
  • ✅ Audio feedback on hover/click
  • ✅ Responsive design
  • ✅ Respects reduced motion preferences
