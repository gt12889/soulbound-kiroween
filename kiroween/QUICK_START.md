# Quick Start Guide

Get up and running with the Dark Productivity Suite in minutes.

## 5-Minute Setup

### 1. Create an Account (Optional but Recommended)

**Why?** Cloud sync, multi-device access, data backup

1. Click "Get Started" on the landing page
2. Choose sign-up method:
   - **Email/Password**: Enter email and create password
   - **Google**: Click "Sign in with Google"
   - **GitHub**: Click "Sign in with GitHub"
3. Complete registration
4. You're in! 🎉

**Skip for now?** You can use the app without an account, but data stays local only.

### 2. Learn the Essential Shortcuts

Master these three shortcuts first:

- **`Ctrl+K`** - Quick Capture (create note or task instantly)
- **`Ctrl+1-4`** - Switch between modules
- **`Ctrl+?`** - Show all shortcuts

### 3. Create Your First Note

1. Press `Ctrl+3` or click "Necronomicon Notes"
2. Click "New Note" or press `Ctrl+N`
3. Type your note title and content
4. Auto-saves as you type ✓

**Pro tip**: Press `Ctrl+M` to enable markdown mode for formatting.

### 4. Add Your First Task

1. Press `Ctrl+4` or click "Graveyard Dashboard"
2. Click "New Task" or press `Ctrl+T`
3. Enter task title and details
4. Watch the tombstone rise! ⚰️

**Pro tip**: Right-click a tombstone to set priority or add tags.

### 5. Try Quick Capture

1. Press `Ctrl+K` from anywhere
2. Type your thought
3. Select "Note" or "Task"
4. Press Enter
5. Done in seconds! ⚡

## Essential Features

### Keyboard Shortcuts

The fastest way to navigate:

```
Ctrl+1  →  Terminal Tarot
Ctrl+2  →  Ghost Writer
Ctrl+3  →  Necronomicon Notes
Ctrl+4  →  Graveyard Dashboard
Ctrl+K  →  Quick Capture
Ctrl+?  →  Show all shortcuts
```

**Full reference**: [KEYBOARD_SHORTCUTS.md](./KEYBOARD_SHORTCUTS.md)

### Themes

Change the atmosphere:

1. Click settings icon (⚙️)
2. Select "Appearance" tab
3. Choose your theme:
   - **Default Dark** - Purple gothic
   - **Blood Moon** - Crimson intensity
   - **Midnight Forest** - Green mystique

### Tags

Organize everything:

1. Open any note or task
2. Click tag icon or press `Ctrl+Shift+T`
3. Type tag name and press Enter
4. Filter by tags in sidebar

### Markdown

Format your notes:

1. Open a note
2. Press `Ctrl+M` for markdown mode
3. Use markdown syntax:
   - `# Header`
   - `**bold**`
   - `*italic*`
   - `` `code` ``
4. See live preview on the right

## Module Overview

### 🔮 Terminal Tarot

**What**: Mystical insights from your git commits

**How to use**:
1. Navigate to Terminal Tarot (`Ctrl+1`)
2. Click "Generate Reading"
3. View your three-card spread
4. Read interpretations based on your coding patterns

**Best for**: Reflection on your development journey

### ✍️ Ghost Writer

**What**: AI-powered writing assistant

**How to use**:
1. Navigate to Ghost Writer (`Ctrl+2`)
2. Start typing
3. Watch for spectral suggestions
4. Hover to see clearly
5. Click to accept or keep typing to dismiss

**Best for**: Creative writing, brainstorming, overcoming writer's block

### 📖 Necronomicon Notes

**What**: Ancient book-styled note-taking

**How to use**:
1. Navigate to Notes (`Ctrl+3`)
2. Create notes with `Ctrl+N`
3. Search with `Ctrl+F`
4. Organize with tags
5. Enable markdown for formatting

**Best for**: Knowledge management, journaling, documentation

### ⚰️ Graveyard Dashboard

**What**: Visual task management with tombstones

**How to use**:
1. Navigate to Dashboard (`Ctrl+4`)
2. Create tasks with `Ctrl+T`
3. Drag to reorder
4. Click to mark complete (watch it sink!)
5. Use moon calendar for scheduling

**Best for**: Task tracking, project management, goal setting

## Power User Tips

### 1. Master Quick Capture

`Ctrl+K` is your best friend. Use it to capture thoughts instantly without breaking flow.

**Workflow**:
- Reading something interesting? `Ctrl+K` → note
- Remember a task? `Ctrl+K` → task
- Quick idea? `Ctrl+K` → note

### 2. Use Tags Effectively

Create a tagging system:
- `work:` prefix for work items
- `personal:` for personal items
- `urgent` for high priority
- `someday` for future ideas

### 3. Pomodoro for Focus

1. Click hourglass icon in Graveyard
2. Set work interval (default: 25 min)
3. Press Space to start
4. Focus on one task
5. Take breaks when timer completes

### 4. Archive Completed Tasks

Keep your graveyard clean:
1. Right-click completed tombstone
2. Select "Archive"
3. Access archive with `Ctrl+Shift+A`
4. Restore if needed

### 5. Export Regularly

Backup your data:
1. Settings → Data Management
2. Click "Export Data"
3. Choose JSON format
4. Download monthly backups

### 6. Customize Shortcuts

Make it yours:
1. Press `Ctrl+?`
2. Click any shortcut to edit
3. Press your preferred keys
4. Save changes

### 7. Use Markdown

Format notes beautifully:
- Headers for structure
- Lists for organization
- Code blocks for snippets
- Links for references
- Tables for data

### 8. Theme for Your Mood

Switch themes based on time or mood:
- **Default Dark**: Balanced, everyday use
- **Blood Moon**: Intense focus sessions
- **Midnight Forest**: Calm, creative work

## Common Workflows

### Daily Planning

1. Open Graveyard Dashboard (`Ctrl+4`)
2. Review yesterday's completed tasks
3. Archive old completed tasks
4. Create today's tasks (`Ctrl+T`)
5. Set priorities (right-click → priority)
6. Start pomodoro timer

### Note-Taking Session

1. Open Necronomicon Notes (`Ctrl+3`)
2. Create new note (`Ctrl+N`)
3. Enable markdown mode (`Ctrl+M`)
4. Write with AI assistance (Ghost Writer)
5. Add tags for organization
6. Search when needed (`Ctrl+F`)

### Creative Writing

1. Open Ghost Writer (`Ctrl+2`)
2. Start writing
3. Accept AI suggestions when helpful
4. Save to notes when done
5. Export as markdown

### Project Management

1. Create project tag (e.g., `project:website`)
2. Add all related tasks with tag
3. Filter by tag to see project tasks
4. Use priorities for task order
5. Archive when project completes

### Weekly Review

1. Export data for backup
2. Review completed tasks in archive
3. Check pomodoro statistics
4. Clean up unused tags
5. Archive old completed tasks
6. Plan next week's tasks

## Troubleshooting

### App Not Loading

1. Check internet connection
2. Clear browser cache
3. Try different browser
4. Disable browser extensions
5. Check browser console for errors

### Data Not Saving

1. Check if signed in (for cloud sync)
2. Check browser storage quota
3. Try manual save (`Ctrl+S`)
4. Export data as backup
5. Clear old data if storage full

### Shortcuts Not Working

1. Check for browser conflicts
2. Try different key combination
3. Customize in shortcuts panel
4. Ensure correct element has focus
5. Check platform (Ctrl vs Cmd)

### Sync Issues

1. Check internet connection
2. Verify signed in status
3. Click sync icon for manual sync
4. Check sync status indicator
5. Sign out and sign in again
