## Customizing Shortcuts

### How to Customize

1. Press `Ctrl+?` to open the shortcuts panel
2. Click on any shortcut you want to change
3. Press your desired key combination
4. Click "Save" to apply changes

### Customization Rules

- **Conflict Detection**: System prevents duplicate shortcuts
- **Reserved Keys**: Some system shortcuts cannot be changed
- **Modifier Keys**: Use Ctrl, Alt, Shift for combinations
- **Single Keys**: Available in specific contexts only
- **Reset**: Click "Reset to Default" to restore original shortcuts

### Best Practices

- **Use Modifiers**: Combine Ctrl/Alt/Shift with letters
- **Avoid Conflicts**: Don't override browser shortcuts
- **Muscle Memory**: Keep frequently used shortcuts simple
- **Consistency**: Use similar patterns across modules
- **Document**: Note your custom shortcuts

## Platform Differences

### Windows/Linux

- Use `Ctrl` as primary modifier
- `Alt` for secondary actions
- `Shift` for variations

### macOS

- Use `Cmd` instead of `Ctrl` for most shortcuts
- `Option` instead of `Alt`
- `Shift` for variations

*Note: The application automatically adapts shortcuts for your platform.*

## Accessibility

### Screen Reader Support

- All shortcuts announced by screen readers
- Focus indicators visible for keyboard navigation
- Skip links available for quick navigation

### Keyboard-Only Navigation

- `Tab` - Move to next interactive element
- `Shift+Tab` - Move to previous interactive element
- `Enter` - Activate button or link
- `Space` - Toggle checkbox or button
- `Arrow Keys` - Navigate within components

## Tips for Efficiency

1. **Learn Core Shortcuts First**
   - `Ctrl+K` (Quick Capture)
   - `Ctrl+1-4` (Module Navigation)
   - `Ctrl+?` (Help)

2. **Master Module Shortcuts**
   - Learn shortcuts for your most-used module
   - Practice until they become muscle memory

3. **Use Quick Capture**
   - `Ctrl+K` is your best friend
   - Capture thoughts without context switching

4. **Customize Wisely**
   - Only customize if defaults don't work for you
   - Keep customizations minimal and memorable

5. **Print This Reference**
   - Keep it handy while learning
   - Review weekly until shortcuts are automatic

## Troubleshooting

### Shortcut Not Working

1. **Check for Conflicts**
   - Open shortcuts panel (`Ctrl+?`)
   - Look for duplicate assignments
   - Resolve conflicts

2. **Browser Shortcuts**
   - Some shortcuts may be captured by browser
   - Try different key combinations
   - Check browser extension conflicts

3. **Focus Issues**
   - Ensure correct element has focus
   - Click in the module before using shortcuts
   - Some shortcuts only work in specific contexts

4. **Platform Differences**
   - Verify you're using correct modifier keys
   - Check platform-specific documentation

### Reset Shortcuts

To reset all shortcuts to defaults:
1. Open shortcuts panel (`Ctrl+?`)
2. Click "Reset All to Default"
3. Confirm reset
4. All custom shortcuts cleared
